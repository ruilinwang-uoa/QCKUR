# 理论节草稿:选择性验证的 Conformal 形式化(MetroPT/RSQ1)

> 供论文 §3(理论)与 §5(结果)使用。数字全部来自 code/runs/metropt3/ 的冻结产物
> (metropt_risk_coverage*.csv, metropt_conformal_table.csv, metropt_l1.csv)。

## 1. 形式化设置

对每个 24h 遥测窗口 $w$,冻结特征提取器给出摘要 $x_w \in \mathbb{R}^d$,两阶层
handler 输出判决 $v(w)$ 与非一致性分数

$$s(w) \;=\; \max_{j \in \mathcal{F}}\; z_j(x_w),$$

其中 $z_j$ 为特征 $j$ 相对本车健康基线的中位数/分位数稳健标准化分数,
$\mathcal{F}$ 为分数特征集。规则层点火(确定性签名)的窗口 $s(w) := +\infty$
(高置信检测输出)。

**选择性预测规则**(阈值 $t$):

$$\text{accept}(w; t) \iff \text{rule}(w) \ \lor\ s(w) \le t
\quad\text{else ABSTAIN}.$$

弃权另由结构条件触发:覆盖率不足(遥测空洞)或 $\ge 2$ 个特征越出基线包络
$3\times[p_{01}, p_{99}]$ 跨度(题库外模式)。

## 2. 名义侧的无分布保证(one-class conformal 校准)

设 $\mathcal{C} = \{w_1, \dots, w_n\}$ 为某车的健康校准窗(本实例化:
$n$ = 114 / 101 / 53,排除 3 个裁决幽灵窗后;排除清单与裁决注记随数据发布)。
在窗口可交换性下(近似成立:窗口按时序抽取,论文如实披露),

$$\Pr\big(s(W_{n+1}) > \hat q_t \,\big|\, W_{n+1} \text{ 健康}\big)
\;\le\; \hat\alpha(t) \;=\; 1 - \frac{\mathrm{rank}(t)}{n+1},$$

即阈值 $t$ 给名义(健康)窗口的**误弃权率**一个有限样本上界 $\hat\alpha(t)$。
实测(A/B/2020 三车):$t{=}4$ 时 $\hat\alpha \in [1.8\%, 2.6\%]$,
$t{=}6$(冻结运行点)时 $\in [0.9\%, 1.8\%]$。

**方向性诚实**(论文必须写明):这是 one-class/异常检测型保证——它约束的是
"把健康窗误判为需弃权/异常"的率。**故障侧**(检出漏检率)没有也无从获得
分布无关保证,因为真实车队没有故障标注校准集;该侧风险以战役实测报告
(risk–coverage 表)。这一不对称本身是可靠性方法论的发现:在役场景中,
保证只存在于名义侧,故障侧是被测经验量。

## 3. 报告级选择性风险(实测对象)

系统 $g$ 在接受窗上的**复合事实错误率**:

$$R_g(t) \;=\; \Pr\big( E(w) = 1 \,\big|\, \text{accept}(w;t) \big), \quad
E(w) = \text{数字错误} \lor \text{矛盾主张},$$

数字错误 = L1 确定性检查器抓到的不可核实数值;矛盾主张 = 报告声明的状态
与遥测隐含状态冲突(歧义措辞不计)。

**实测(B8,冻结运行点 $t{=}6$;检查器模式修正后,2026-09-22)**:
- 覆盖率 99.0%(104/105 窗接受);
- 数字错误风险 2.9%(3/104:一处真算术错、一处基线错配、一处边界);
- **复合事实错误风险 3.9%**(初报 14.4% 中 13 处经逐例分解确认为检查器
  词法伪影——报告原文均为 "nominal parameters with deviations that
  require monitoring",检查器模式漏认 "require monitoring" 一词形;修正
  后 B8 分类失败 14→1,L1 0.938→0.988,Final 92.1→93.8,B8−B1 差距
  4.1→2.4,与轴承无伪影协议的 1.2 同量级——测量伪影叙事第三次前瞻性
  复现);
- 行动建议失配率 28.6%,且随阈值放松单调上升(33% 覆盖时 14.7%)——
  **行动风险的选择性梯度**,为决策支持场景给出"覆盖-行动风险"权衡曲线。

对照:B3/B5 数字错误 0(它们复述摘要数字),但其状态矛盾率(L1 分类 +
L2 contra 0.17/0.11 vs B8 0.03)与漏检(0/9 vs 8/9)构成其余维度的
失败——**选择性风险的正确呈现是多维的,单看数字风险会误导**。

## 4. 与既有线的关系(定位)

- conformal RUL 区间(Javanmardi 2023;Xu 2026 split-CP):输出侧区间;
  本文验证**生成报告的事实内容**,对象从数值预测变为自然语言声明集;
- conformal factuality / selective generation for LLM(2024–2026):通用
  NLP 侧;本文给出工业在役实例化 + 名义侧保证与故障侧实测的完整分解;
- physics-informed ML(Xu RESS 2023/2025):本文的规则层是**知识层**
  physics-informed(运营方规则+失效物理签名进入知识与判决,而非损失函数),
  与数据驱动打分层构成混合结构;
- KRAIL(RESS vol 265)/Di Maggio 2025:把 LLM 幻觉列为挑战;本文交付
  名义侧带保证、故障侧可测的界。

## 5. B8R 修复环消融(已完成,诚实负结果)

生成→**确定性检查器**(L1 规则,不含裁判——反循环性红线)→定向修复→复检
(≤2 轮),105 窗、16 处触发:
- 数字错误 3→1(真算术错被修复);
- 但**医源性损伤**:全量重生成扰动已通过句,4 窗新坏;修复提示还把内部
  标签字面(`'monitor_deviation'`)漏进自然语言正文;
- 修正检查器后 B8R L1 = 0.972 < B8 0.988 —— **朴素修复环净负**。
- 论文结论:架构原生自检可修数字错误;句级差分修复(只编辑被标记句)是
  把界收紧到模板水平的正确路径,留作后续工作。
