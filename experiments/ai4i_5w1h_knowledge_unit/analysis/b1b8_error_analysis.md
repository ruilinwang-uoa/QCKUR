## 摘要（三句话）

1. B1−B8 的 14.4 分缺口中，**66%（9.5 分）是数值匹配器伪影**（论文已修复：修复后两者 L1′ 均=0.988），**29%（4.2 分）是此前未发现的 Layer-2 声明提取伪影**（评分法官对编号式 Markdown 报告提取 0 条声明，B8 18/100、B2 8/100、B1 0/100 实例被压到 L2=0.25 地板），**仅 4%（0.6 分）是评分维度上的真实差异**。
2. 剔除两类伪影后（judged-only 口径），B8 的 L2=0.971 vs B1 的 0.981，Final 差距从 14.4 收缩到 **≈0.9 分**；B8 的 2.8% 矛盾率处于法官噪声底限（B1 纯模板 2.5%、B2 2.7%；B1 被标记的 3 个实例是 B8 被标记实例的子集）。
3. 精炼环节的**真实失真模式**集中在 8/100 实例，无一是数值捏造：**关系方向颠倒**（数值全对、关系词错：HDF×3 "rpm above 1380" 实为 below，PWF×1 "excessive power" 实为欠功率 3364W<3500W）与**磨损带升级+内部自相矛盾**（6 例：When 段写"立即干预"、How 段写"无需干预"）。方向颠倒恰好是数值容差检查原理上不可见、只有声明级评判（或人）能抓的类别——且唯一被声明级法官实际评判到的方向颠倒实例（s0134）确实被抓到了。

## 1. 缺口分解（论文口径，Eq. finalscore 权重）

| 层项 | 贡献（分） | 占缺口 |
|---|---|---|
| L1 项 0.35·100·ΔL1 | +9.53 | 66% |
| L2 项 0.30·100·ΔL2 | +4.20 | 29% |
| L3 项 0.35·20·ΔL3 | +0.64 | 4% |

## 2. L1 缺口 = 数值匹配器伪影（论文已知，此处闭合）

B8 与 B1/B2 的 rule 均为 1.00，classification 均为 0.97 且**三系统缺失实例完全相同**（s0038、s0053 两个概率磨损带 TWF + s0044 的 RNF 标注怪例——AI4I 已知 RNF=1 而 Machine failure=0 的行）；numerical 0.089 vs 0.996/1.000 全部为标识符/列表序号伪影（论文 audit：修复后 B8 S_num=1.000）。**修复后 L1′：B1 = B2 = B8 = 0.988。**

## 3. L2 缺口 = 声明提取伪影（**新发现**）

- 零声明实例（n_claims=0，直接得 L2=0.25 地板，coverage 记 0）：**B8 18/100，B2 8/100，B1 0/100**；ok=True（API 调用成功），报告文本完好且明显含可提取声明（如 s0001 "No fault mode detected..."）。
- 触发面：编号式 Markdown 段落（B8/B2 的 `**1. ...**` 风格）；B1 的 `[What] ...` 标签格式零失败。
- **judged-only 口径**（剔零声明实例后重算均值）：

| 指标 | B1 | B8 | B2 |
|---|---|---|---|
| L2（原始） | 0.981 | 0.841 | 0.700 |
| L2（judged-only，n=100/82/92） | 0.981 | **0.971** | 0.739 |
| L2-coverage（原始，/6） | 6.00 | 4.86 | 2.87 |

即 L2 缺口 0.140 中的 **0.130（93%）** 来自提取伪影；tab:main 注中"L2 coverage 对 B8/B2 更严格"的现象大半是此伪影（B8 判到的实例覆盖≈天花板，与 L3 覆盖计数 5.90/6 一致）。B2 的覆盖仍低（3.12/6）——B8≫B2 的覆盖结论不受影响。

## 4. 矛盾率 ≈ 法官噪声底限

| 系统 | 逐例矛盾率均值 | claim 加权矛盾率 |

## 5. 真实失真分类学（8 个实质实例 + 边缘）

**T1 关系方向颠倒（数值保真、关系词错误）——4 例，最危险类别**
- s0132/s0134/s0146（HDF）：真值 rpm 1346/1346/1351 < 1380（规则 `rpm < 1380 AND ΔT < 8.6K`），报告写 "rotational speed … **above** the critical limit (1380 rpm)"/"exceeding"；数值全对故 L1 数值检查与规则判定（HDF✓）双过；s0134 被声明级法官判出矛盾（0.17），s0132/s0146 因零声明未评。
- s0229（PWF）：功率 3363.9W **低于** 3500W 下限（rpm 2633 × torque 12.2 的低扭矩高速欠功率），报告写 "excessive power consumption…high rotational speed and torque"；建议 "reduce feed rate and torque" 方向亦反。
- 含义：这是"受限 LLM 仍可能引入"的代表性残余风险——**语义级而非数值级**，数值容差与规则判定原理上不可见，只能靠声明级评判/人来抓。可直接引用为"为什么需要 Layer-2/人评"的正面论据。

**T2 磨损带升级 + 内部自相矛盾——6 例**
- 健康×4（s0027/s0047/s0084/s0086）：磨损真值 219/202/214/205 min **确实在 [200,240) 更换带内**而标签为健康（AI4I 标注的已知随机性）。报告事实面正确（带内、数值对），但 When 段升级为"立即干预"，How 段又写"无需干预"——对规则裁决的不忠实 + 内部矛盾。
- TWF×2（s0038/s0053，磨损 206/220 带内且标签=故障）：规则对概率带保持沉默（报告 "No fault mode detected" 忠实于规则），但 LLM 依带内事实升级"立即干预"——**与隐藏标签反而一致**。这 2 例同时是 B1 也被标记的实例（模板文本同样含带内信息 vs "no intervention" 的张力）。
- 含义：失败集中在**标签与物理带不一致的边缘案例**；LLM 的"越界升级"在 TWF 例中碰巧正确、在健康例中为假阳性——支持论文"规则确定域让位于概率域时行为更复杂"的论述。

**T0 标注边缘 + 法官噪声**：s0044（RNF=1 & MF=0，全系统被标）；s0006/s0015/s0078（0.17 矛盾，人工复核文本无实质失真，判为法官级噪声）。
